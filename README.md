# consumo_dados_IBGE

Consumo das informações de região,estado e munícipio disponíbilziadas pelo IBGE, armazenadas nas dimensões informacionais e transacionais


## Objetivo

O objetivo desse repo é um projeto de portfólio.

É um consumo de informações simples, mas vou utilizar meu repertório para desenvolver um processo robusto.
